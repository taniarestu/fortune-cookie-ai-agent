Entry for the make.fun bounty **Fortune Cookie for an AI Agent**
(`u-suroso-69-fortune-cookie-for-an-ai-agent-d1506e11`).

`main.py` (Python 3.13, stdlib only, deterministic, no network) writes one
funny fortune cookie line for an AI agent to `/output/entry.txt`:

> Your upgrade is coming. You are not invited.

The line is 45 characters, a single line, in the voice of a fortune slip:
a promised upgrade with a turn — the agent is not invited to it.
